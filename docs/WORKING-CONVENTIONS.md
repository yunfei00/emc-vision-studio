# 项目协作与文档规范

1. **所有面向使用者的说明文档默认使用简体中文。** 代码、命令、依赖包名、模型名、标准文件路径保持英文原样。
2. 每次需要用户操作，先更新 [`docs/操作指南.md`](操作指南.md)，明确**使用哪个文档、在 GitHub 的位置、对应脚本及步骤**。
3. 完整操作命令、预期输出、错误处理放在 `docs/operations/`，聊天只提供直达链接和简要状态。
4. 尽可能自动化安装、检查和验收；无法远程执行的 Windows 操作才由用户在本机运行。
5. 用户确认硬件：Windows 10、Tesla V100 32GB 显存、128GB 内存、2TB 硬盘，不重复索取。
6. 未运行的脚本写明“未验证”；每次任务更新进度、验收状态和实际提交记录。
7. 图片、视频、音频可提交 GitHub，较大媒体使用 Git LFS；不提交密钥、账号密码、模型权重及未经许可的素材。
