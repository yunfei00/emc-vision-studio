# 项目协作规范

1. 面向用户的文档一律使用简体中文，代码、命令和模型名保留原文。
2. **Python 环境统一使用 uv**：`uv python install`、`uv venv`、`uv pip install`，不使用 Conda 或传统 pip 命令。
3. 统一操作入口为 [docs/操作指南.md](操作指南.md)；每次任务都说明使用哪个文件和所在路径。
4. 完整可复制步骤写入 GitHub，聊天只给简短结果和直达链接。
5. 硬件基线固定为 Windows 10、Tesla V100 32GB 显存、128GB 内存、2TB 硬盘。
6. 未实机执行的安装或 Demo 不得标记通过；记录实际提交 SHA 和验收证据。
7. 视频、图片、音频允许入库，大文件使用 Git LFS；密码、令牌、未经授权素材仍不得公开。
