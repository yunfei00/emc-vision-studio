# Lesson 01 — ComfyUI local environment

Goal: reproducible, isolated deployment on RTX 5090. Check GPU and driver first; select compatible Python/PyTorch; install ComfyUI; verify local UI and GPU execution; document pinned versions. Acceptance requires evidence, not just successful package installation.

Commands: `bash scripts/check_gpu.sh` then review `docs/environment/installation.md`. Do not expose ComfyUI directly to public network.
