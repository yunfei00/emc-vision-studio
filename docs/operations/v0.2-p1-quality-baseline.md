# v0.2-P1｜本地视频质量基线

v0.1.0 Tag/Release 已由用户在 Termux 完成并通过 `gh release view` 验证。

本阶段只检查本地视频的时长、编码、帧率、音视频轨道和已有 SVD 片段长度。**不会重新生成视频，不会上传内部素材，也不会把本地质量报告提交到 GitHub。**

在 **Windows 10 电脑**的仓库根目录执行（不是手机 Termux）：

```powershell
git fetch origin
git switch feature/v0.2-quality-upgrade
git pull --ff-only
powershell -ExecutionPolicy Bypass -File .\scripts\v02_p1_quality_baseline.ps1 -Root "D:\AI-Video"
```

结果保存到：

`D:\AI-Video\private\lost-signal\v0.2\p1\quality_baseline.json`

只需要反馈“v0.2-P1 成功”或非敏感报错类型。报告包含本地路径，不要外传。

**说明：** 此初版基线主要统计容器/镜头时长，并未可靠量化每个镜头真实运动帧占比；下一步根据真实 SVD 文件分布补齐动态比例检测，避免将时长误认为真实运动量。
