# v0.2-P2 动态镜头预览操作指南

## 当前进度

- 单镜头预览：用户已反馈 P2 COMPLETE，运行验收通过。
- 多镜头合成：首次执行因找不到 S01-S19 命名而失败。

- 注意：无标签预览不代表真实故事镜头顺序，也不能认定 19 个镜头全部覆盖。正式剪辑前必须确定镜头映射。

## Windows 10 操作

在 GitHub 仓库根目录打开 PowerShell，执行：

```powershell
git switch feature/v0.2-quality-upgrade
git pull --ff-only
& "D:\AI-Video\.venv\Scripts\python.exe" .\scripts\v02_p2_multi_shot.py --root "D:\AI-Video"
```

成功时输出 P2 ASSEMBLY COMPLETE、Shots、Missing scenes、Mapping mode 和 Preview seconds。

其中 Mapping mode 为 scene_labels 表示按文件名镜头标签匹配；unlabelled_preview 表示按文件路径顺序生成的技术预览，**不是故事顺序**。此时 Missing scenes 仍可能为 19，属于未知映射，不代表全部素材缺失。
