# v0.2-P2 多镜头动态合成：中文操作指南

## 结果与修复

上次输出 Shots 19、Missing scenes 19、unlabelled_preview、76 秒，说明旧程序将 19 个无标签 MP4 拼成了技术预览，**不能代表真实 19 镜头**。

核对 v0.1 源代码后确认，真实源文件命名是 S001.mp4 至 S019.mp4，而不是 S01.mp4 至 S19.mp4。旧脚本还可能混入 phase6 的合辑或 phase9 的粗剪文件。现已修正：

- 只读取 phase6/S001.mp4 至 S006.mp4、phase9/S007.mp4 至 S019.mp4。
- 严格按 plans/phase8_lost_signal_storyboard.json 的故事顺序排列。
- 缺失镜头明确统计，不再按任意文件顺序替代。
- 保留原素材，仅生成独立预览。预览仍非 103 秒最终成片。
