# v0.2 周末无人值守队列｜中文操作指南

## 本次能做什么
基于现有 19 镜头动态缺口计划，按缺口从大到小，自动为每个原始镜头提取末帧，并用现有 ComfyUI SafeMode 已验证 SVD 工作流生成**一段** 14 帧、6 FPS 的动态续接候选。默认最多处理 19 镜头，每镜头最多一次，失败记录后跳过，支持重启后跳过已完成结果。

**重要限制：** 这不是高清修复、人物身份锁定或结构形变修复；SVD 续接也不保证无变形。结果统一标记“待人工观看验收”，不自动覆盖原视频或 v0.1.0。若首个镜头质量不满意，先停止，不建议周末全量生成。

## 开始前
- Windows 10 电脑保持开机不休眠，V100S 32GB 无其他 GPU 任务。
- ComfyUI 按此前验证的 SafeMode 启动，服务地址 http://127.0.0.1:8188。
- 确认 FFmpeg 在 PATH、原始 phase6/phase9 视频存在、至少预留 25 GB 磁盘空间。
- 确认此前已生成 private/lost-signal/v0.2/p2/motion_extension_plan.json。
- 请勿把私有视频、图像或日志上传 GitHub。

## 运行（PowerShell，在仓库根目录）

```powershell
git switch feature/v0.2-quality-upgrade
git pull --ff-only
& "D:\AI-Video\.venv\Scripts\python.exe" -m py_compile .\scripts\v02_p2_generate_continuation.py .\scripts\v02_weekend_queue.py
& "D:\AI-Video\.venv\Scripts\python.exe" .\scripts\v02_weekend_queue.py --root "D:\AI-Video" --dry-run
```

先进行**一个镜头的实际试运行**：

```powershell
& "D:\AI-Video\.venv\Scripts\python.exe" .\scripts\v02_weekend_queue.py --root "D:\AI-Video" --max-scenes 1
```

检查该镜头新视频是否模糊、脸型/身体/手指变形。若不满意，请勿开启全量队列。

确认单镜头效果可接受，再运行完整队列（请保持 PowerShell 窗口开启）：

```powershell
& "D:\AI-Video\.venv\Scripts\python.exe" .\scripts\v02_weekend_queue.py --root "D:\AI-Video" --max-scenes 19
```

队列会自动跳过已生成的候选片段；最多处理 19 个镜头，不会无限生成，也不会自动反复消耗 GPU。运行中可查看本地 `D:\AI-Video\private\lost-signal\v0.2\p2\weekend_queue\report.json`。

## 停止、恢复
在另一 PowerShell 窗口输入：

```powershell
New-Item -ItemType File -Force "D:\AI-Video\private\lost-signal\v0.2\p2\weekend_queue\STOP"
```

当前镜头执行完后停止；不会中断当前 ComfyUI 推理。恢复前删除 STOP：

```powershell
Remove-Item "D:\AI-Video\private\lost-signal\v0.2\p2\weekend_queue\STOP" -ErrorAction SilentlyContinue
```

然后重新执行完整队列命令。若报 running.lock 已存在，先检查是否有队列正在运行，不要在运行中删除锁文件。
