# 操作指南（当前只看这一页）

## 当前任务：修复 Phase 2 脚本编码错误

**2026-10-09 已修复：** 旧版 `scripts/verify_and_prepare_phase2.ps1` 的第 8 行包含中文字符串，在 Windows PowerShell 5.1 中可能发生 UTF-8 无 BOM 解码错误。新版脚本全部采用 ASCII 字符，避免此类解析问题。

### 1. 在本地项目根目录打开 PowerShell

项目目录名称：`emc-vision-studio`。确保 PowerShell 当前位于此文件夹。

### 2. 更新脚本（必须先执行）

```powershell
git pull
```

### 3. 重新运行修复后的脚本

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify_and_prepare_phase2.ps1 -Root "D:\AI-Video"
```

如果安装时使用的是 C 盘，则改成：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify_and_prepare_phase2.ps1 -Root "C:\AI-Video"
```

### 4. 成功标志

看到：

```text
CUDA COMPUTE PASS
VERIFICATION COMPLETE
```

即表示 GPU 基础 CUDA 计算已通过。脚本还会打印 PyTorch/CUDA 版本及已有模型目录。

### 5. 如果仍提示第 8 行错误

先执行：

```powershell
git log -1 --oneline
Get-Content .\scripts\verify_and_prepare_phase2.ps1 -TotalCount 10
```

确认第 8 行已经是英文 Python 代码，不包含中文。如果 `git pull` 提示本地文件冲突，请不要直接覆盖你的本地改动，先反馈错误。
