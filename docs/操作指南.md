## 当前问题：原下载太慢

已经改用 **ModelScope 魔搭国内下载方案**。旧 Hugging Face 下载窗口可按 `Ctrl+C` 停止，不需要重新安装 ComfyUI。

**现在打开这个文档：** [Phase 2：国内 ModelScope 下载优先方案](operations/2026-10-09-phase2-first-image.md)

本地路径：`emc-vision-studio\docs\operations\2026-10-09-phase2-first-image.md`

在本地 `emc-vision-studio` 项目根目录打开 PowerShell：

```powershell
git pull
```

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\download_modelscope_sd15.ps1 -Root "D:\AI-Video"
```

如果安装目录不在 D 盘，请修改 `-Root`。后续重启 ComfyUI 和生成图片的命令都在上面的详细文档中。

注意：魔搭下载的是约 4GB 的 `.ckpt`，与此前 HF 的约 2GB `.safetensors` **不同**，不能混用部分下载文件。
