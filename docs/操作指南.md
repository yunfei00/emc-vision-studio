# 操作指南｜当前状态：首张图片已生成成功

2026-10-10 用户确认 Tesla V100S 32GB 已经成功生成一张图片。CUDA 兼容性问题在当前配置下不再阻止首图生成。

## 当前稳定启动方式

在 `emc-vision-studio` 项目根目录打开 PowerShell：

```powershell
git pull
```

启动 ComfyUI：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_windows_v100.ps1 -Root "D:\AI-Video" -SafeMode
```

在另一窗口生成第一张图片：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\generate_first_image.ps1 -Root "D:\AI-Video" -Model modelscope
```

生成图片在 `D:\AI-Video\ComfyUI\output`，文件名前缀 `lost_signal_lab_S001_`。
