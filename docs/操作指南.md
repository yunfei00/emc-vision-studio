# 操作指南（当前只看这一页）

> 当前阶段：ComfyUI 已安装，网页已能打开。**不要重复安装。**

## 第一步：找到本地项目目录

如果你之前在电脑上克隆过 `emc-vision-studio`，打开这个文件夹，在地址栏输入 `powershell` 并回车，即可在该文件夹打开 PowerShell。

如果你还没有下载项目，请在准备存放项目的目录打开 PowerShell，复制：

```powershell
git clone https://github.com/yunfei00/emc-vision-studio.git
cd emc-vision-studio
```

## 第二步：更新 GitHub 文件

在 **emc-vision-studio 项目根目录** 的 PowerShell 中执行：

```powershell
git pull
```

成功后应能在项目中找到 `scripts\verify_windows_v100.ps1`。

## 第三步：执行 CUDA 验证（现在需要做的事）

仍在项目根目录，复制下面这条命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify_windows_v100.ps1 -Root "D:\AI-Video"
```

**注意：** 上面 `D:\AI-Video` 是之前安装脚本的默认目录。如果你当时改过 `-Root`，这里必须改为相同目录。例如 ComfyUI 安装在 `C:\AI-Video`，则命令为：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify_windows_v100.ps1 -Root "C:\AI-Video"
```

### 如何判断成功

终端出现：

- `GPU 架构: (7, 0)`
- `CUDA 矩阵运算：通过`

说明 Tesla V100 的基础 CUDA 运算正常。**这不代表视频模型已验证。**

### 如果提示“找不到文件”

说明你没有在 `emc-vision-studio` 项目根目录，或尚未执行 `git pull`。可先执行：

```powershell
Get-Location
Test-Path .\scripts\verify_windows_v100.ps1
```

第二条应显示 `True`。若显示 `False`，回到第一步找到正确的项目目录。

### 如果提示“找不到 uv 环境”

核对安装时使用的根目录，检查 `D:\AI-Video\.venv\Scripts\python.exe` 是否存在；如果安装在别的盘，修改 `-Root`，不要重新安装。

## 关于 OpenGL 提示

后台的 `no opengl-accelerate module loaded` 不等于 CUDA 故障。网页已经打开，先做 CUDA 实算验证，不必为了这一条提示重装环境。
