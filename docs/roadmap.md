# Roadmap V1.0

| Phase | Scope | Deliverable | Gate |
|---|---|---|---|
| 0 | Project charter, repository, governance | Docs, templates, checklist | Files committed and verified |
| 1 | GPU and ComfyUI | Reproducible install scripts, versions, smoke-test logs | GPU inference and short render verified |
| 2 | Technical script and storyboard | Reviewed screenplay, shot list, prompts | EMC technical review |
| 3 | Shot generation | Consistent character/scene shots and metadata | Visual QC and continuity |
| 4 | Postproduction | Master edit, subtitles, soundtrack, 30s cut | Playback and quality checks |
| 5 | Enterprise release | Approved promotional deliverables | Brand/legal/technical signoff |

Tentative 14-day schedule; depends on model compatibility and iteration. Keep evidence in `docs/acceptance/` and production QA. Each phase must have a commit and acceptance record. Never mark a phase passed solely from a plan.
