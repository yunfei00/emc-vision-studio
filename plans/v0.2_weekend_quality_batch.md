# v0.2-P2/P3 周末无人值守高质量生产方案

## 目标
在 Windows 10、V100S 32GB、现有 ComfyUI SafeMode 环境下，改善《消失的信号》的图片清晰度、工程师人物一致性、脸部/身体/手指形变与视频稳定性。禁止声称仅靠超分就修复结构形变。103 秒目标不等于 103 秒真实运动。

## 当前实测
- 19 个原始镜头正确映射，storyboard 模式
- 原始 SVD 时长 44.332 秒；103 秒时间线缺口 58.668 秒
- 高优先级 8 镜头、中优先级 11 镜头
- S006 续接候选缺口 3.667 秒，末帧已提取
- v0.1.0 必须冻结；本地私有媒体绝不上传 GitHub

## 生产原则
1. 先建立固定的虚构中国男性 EMC 工程师角色参考（30 岁、短黑发、深蓝工作服），以参考图驱动各分镜；单靠文字提示词不能保证身份一致。
2. 先做 1~2 个高质量关键帧候选，检查脸部、手指、连接器与仪器细节。可分阶段高清修复，但不得把锐化当作结构修复。
3. 对人物镜头限制夸张动作、快速转头和复杂手势；视频从稳定关键帧开始，先小批量验证连续性。
4. 每镜头多候选、可复现随机种子、质量记录、人工复核标记；自动清晰度或相似度评分不能保证没有形变。
5. 生成脚本必须可断点续跑、失败跳过/有限重试、检查磁盘余量与 GPU 环境，不能无限循环；写入 private/lost-signal/v0.2，绝不覆盖原始 phase6/phase9。
6. 周末无人值守应有单实例锁、超时、每镜头进度日志、质量报告、失败清单和停止开关。任何模型/节点/环境变化必须先预检。
7. 不直接启用不兼容的高端视频模型；V100S 与 SafeMode 的已验证 SVD 工作流优先，其他增强模型需单独兼容性验证。
8. 所有用户操作文档必须中文，提供可复制的 PowerShell 命令；代码提交后进行 Python 编译与最小离线测试。

## 建议实施阶段
- P2-QA：离线审计现有 19 段视频（时长、分辨率、帧率、黑帧/重复帧、模糊度）并生成本地报告。
- P3-Character：统一角色参考与高质量关键帧试验；审核成功后扩展。
- P3-Video：短视频候选、连续性/稳定性筛选，优先 8 个高缺口镜头。
- P3-Batch：安全的夜间无人值守队列，具备断点续跑、磁盘与显存保护、失败报告。
- P3-Review：下周人工观看验收，未通过镜头不自动宣称合格。

## 周末开机条件
Windows 电脑保持供电、禁用自动休眠，ComfyUI 按已验证 SafeMode 启动，GPU 不被其他任务占用，磁盘空间充足；没有本地启动程序，就不会自动在远程运行。
