# v0.2-P3 人物结构与身份一致性整改方案

## 问题判定
用户反馈人物脸部糊/扭曲，胳膊不连续。现有 SVD 末帧续接易累计结构错误；提高分辨率或增加随机种子不能保证人体正确。所有人物镜头暂不进入自动“合格”状态。

## 分镜风险分级
根据 phase8_lost_signal_storyboard.json 的文字提示词，S007、S009、S010、S012、S013、S014、S015、S017、S018、S019 明确涉及人物；其中 S010、S013、S015、S018 含手臂/手部操作，风险较高。S008、S011、S016 为无人物特写。S001-S006 尚需根据原始图像人工确认，不能凭 ID 推断。

## 修复顺序
1. 停止继续用已变形末帧做人物视频续接。保留已有候选供比较，不覆盖原素材。
2. 为虚构中国男性 EMC 工程师建立正面、半侧面、全身的统一参考图和服装、发型、面部特征规范；先人工确认角色，再批量。
3. 人物镜头重新生成结构正确的静态关键帧。复杂手部操作优先拆成手部特写与仪器特写，降低手臂运动幅度；优先镜头静止、人物微动。
4. 如果现有 ComfyUI SafeMode 有兼容的 ControlNet/OpenPose、参考图身份保持节点，先独立检查节点与模型可用性，**不得未经验证自动下载、安装或更改环境**。不具备条件则退回静态关键帧+有限镜头运动方案。
5. 对每个角色镜头进行脸部结构、双臂连接、手指数量、人物身份、跨帧闪烁的人工验收。模糊检测只能筛查清晰度，不能证明人体结构正确。
6. 无人物镜头可继续原 SVD 方案；人物镜头必须通过静态图验收后才能生成动态。
7. GPU 长时运行采用受限队列、失败跳过、断点续跑和本地报告；禁止对失败角色镜头无限重试。
8. 不改变 v0.1.0；所有图片视频保存在 D:\AI-Video\private\lost-signal\v0.2 下。

## 验收标准
- 人物身份、发型和服装保持一致
- 脸部五官清晰且无明显扭曲
- 肩膀、手臂、手掌连接自然，无多余肢体
- 关键动作不出现明显关节跳变
- 画面无严重模糊、重复帧或明显闪烁
- 不通过镜头单独记录并重新制作，绝不宣称 100% 自动无形变

## 现阶段建议
在原有周末续接队列结束后先看 report.json；下一轮先做人物素材质量盘点与一张角色标准参考图，不能直接全量生成。
