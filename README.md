# EMC Vision Studio

Local AI video production and technical storytelling about smartphone EMC/GNSS interference. First production: 《消失的信号》, 90–120s main film plus 30s cutdown.

## Confirmed workstation
**Windows 10 · NVIDIA Tesla V100 32GB VRAM · 128GB system RAM · 2TB disk.** This supersedes the RTX 5090/Linux proposal. Driver version remains unknown, and is not needed for the current planning stage.

## Workflow
Phase 0 project baseline; Phase 1 compatible ComfyUI environment and first render; Phase 2 technical script/storyboard; Phase 3 shot generation; Phase 4 editing/audio; Phase 5 company release. See `docs/roadmap.md` and `docs/progress.md`.

## Asset management
Keep scripts, learning logs, prompts, workflows, generated images, audio and video in this public project; use Git LFS for media. Model weights and caches remain outside Git. Never commit credentials or unlicensed materials. Synthetic measurement imagery is illustrative, not actual test evidence.
