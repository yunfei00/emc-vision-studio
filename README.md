# EMC Vision Studio

AI-powered EMC storytelling and video production. Public engineering documentation and reproducible workflows for an enterprise promotional film about smartphone GNSS electromagnetic interference.

## First production
`productions/001-lost-signal/` — 《消失的信号》 (The Lost Signal), a fictionalized technical narrative. Target: 90–120 s main film and 30 s cutdown, 16:9. No synthetic measurements may be presented as actual test evidence.

## Phases
0. Project charter and governance (this baseline)
1. RTX 5090 / PyTorch / ComfyUI installation and GPU verification
2. Script, engineering review and storyboard
3. Image and video shot production
4. Sound, subtitles, editing and finishing
5. Technical, legal and brand approval; company delivery

Start at [roadmap](docs/roadmap.md), [progress](docs/progress.md), and [acceptance](docs/acceptance/phase-0.md).

## Safety and publication
Public repo: **never commit** internal product drawings, actual RF test data, confidential device details, credentials, licensed third-party media or unpublished company information. Large model weights and renders remain outside Git; publish only cleared deliverables. Commercial rights require review before publication.
